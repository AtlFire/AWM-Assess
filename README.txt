PROPERTY WILDFIRE ASSESSMENT: standalone app files

Files: index.html (the app), manifest.webmanifest, sw.js (offline support), and three icons.
Keep all files together in one folder. The icon is a placeholder; replace the PNGs with your logo (same file names and sizes).

HOW TO PUT IT ON YOUR IPAD
1. Put this folder on any web host that serves files over https. Free options include Netlify (drag the folder onto its deploy page), GitHub Pages, or Cloudflare Pages. Steps change, so follow each host's current instructions. You only need to host the files: no server or database.
2. On the iPad, open the web address in Safari.
3. Tap Share, then Add to Home Screen. It now opens like an app, full screen.
4. Open it once while online so it can save itself for offline use, then test with Airplane Mode before relying on it in the field.

YOUR DATA
- Assessments and photos are saved inside the iPad's browser storage for that web address. They are not sent anywhere.
- Data from the Claude version does not carry over automatically. In the Claude version tap Save backup, then in the new app tap Restore backup.
- Save a backup after every job. Deleting the app, clearing website data, or losing the iPad loses the data.
- Test saving, sharing and printing on your own iPad before using it with a client.

BEFORE CLIENT USE (needs a person)
- Have a qualified assessor review the checklist text and scoring.
- Have a lawyer review the disclaimer and privacy notice.
- Replace the placeholder logo and fill in Settings.
